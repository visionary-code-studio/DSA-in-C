## 📌 About This Repository

Welcome to **DSA in C**! 💻

This repository contains implementations of important Data Structures
and Algorithms concepts in the C programming language.

The source code is divided into **3 buckets**, making it easier to
navigate, practice, understand, and revise individual concepts.

> 📂 Click on any bucket or topic below to navigate directly to its source folder.
